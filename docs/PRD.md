# PRD — Продуктовые требования TransApp

## 1. Видение продукта

**TransApp** — личный переводчик поверх Telegram. Пользователь получает инструмент, который:
- Переводит входящие сообщения **только для него** (не засоряя чат)
- Переводит исходящие перед отправкой
- Авто-переводит выбранные чаты/каналы в Mini App

---

## 2. Целевая аудитория

| Сегмент | Описание |
|---|---|
| **Личный пользователь** | Общается в мультиязычных чатах/каналах |
| **Экспат / путешественник** | Живёт в стране с чужим языком |
| **Бизнес-пользователь** | Ведёт переговоры с иностранными партнёрами в TG |
| **Админ группы/канала** | Хочет сделать сообщество мультиязычным |

---

## 3. Пользовательские сценарии

### Сценарий 1: Перевод входящего сообщения по команде

**Актор:** Личный пользователь
**Триггер:** Пользователь видит сообщение на незнакомом языке

```
Шаги:
1. Открывает любой чат (личный, группа, канал)
2. Видит сообщение на чужом языке
3. Reply на сообщение → /tr  (или @transappbot tr)
4. Бот отвечает ТОЛЬКО ПОЛЬЗОВАТЕЛЮ в личке (ephemeral)
5. В общем чате ничего не появляется

Edge-cases:
- Сообщение уже на языке пользователя → "Уже на [язык], перевод не нужен"
- Сообщение = только медиа без текста → "Нет текста для перевода"
- Текст > 5000 символов → разбивается на части, переводится батчем
- Превышен лимит (freemium) → уведомление + кнопка "Апгрейд"
- Бот не в группе → инструкция по добавлению
```

**Граф состояний:**
`idle → awaiting_reply → translating → done | limit_exceeded | error`

---

### Сценарий 2: Перевод исходящего (inline-режим)

**Актор:** Личный пользователь
**Триггер:** Хочет написать на языке собеседника

```
Вариант А — личка с ботом:
1. Пишет боту: /to en Привет, как дела?
2. Бот: "Hello, how are you?"
3. Копирует → вставляет в нужный чат

Вариант Б — inline (приоритет для MVP):
1. В любом чате: @transappbot Привет как дела
2. Появляется inline-список: 🇬🇧 Hello... | 🇩🇪 Hallo... | 🇫🇷 Bonjour...
3. Выбирает язык → сообщение отправляется от имени пользователя

Edge-cases:
- Язык не указан → язык по умолчанию из настроек
- Уже на целевом языке → предупреждение
- Inline не включён в BotFather → объяснение
```

### Сценарий 3: Авто-перевод канала/чата в Mini App

**Актор:** Личный пользователь
**Триггер:** Подписан на канал на другом языке

```
Настройка:
1. Открывает Mini App
2. "Добавить чат" → вставляет ссылку/@username
3. Выбирает: язык источника (авто / фиксированный) → язык назначения
4. Включает триггер: при открытии Mini App / по расписанию

Работа:
5. Сервис забирает последние N сообщений (Bot API getUpdates / webhooks)
6. Переводит батчем (кэшируя одинаковые строки)
7. Показывает в Mini App двухколоночно: оригинал + перевод

Edge-cases:
- Приватный чат без бота → v2 (MTProto/userbot)
- Очень активный чат → лимит: 50 новых сообщений/запрос
- Медиа с caption → переводить только caption
```

---

### Сценарий 4: Настройки в Mini App

```
Дашборд:
- Остаток символов / тариф / дата обновления
- Активные авто-переводы (список чатов)
- График использования за 30 дней

Настройки:
- Язык по умолчанию (куда переводить)
- Любимые языки (для inline — показывать первыми)
- Уведомления о лимите (порог: 20% / 10% / 0%)
- Движок перевода (если несколько: Google / DeepL / GPT)

Биллинг:
- Текущий план + кнопка апгрейда
- История транзакций
- Реферальная программа
```

---

### Сценарий 5: Мультиязычная группа (v1.5)

**Актор:** Администратор группы

```
Настройка:
1. Добавляет @transappbot в группу (нужны права: читать сообщения)
2. /group_translate on
3. Настраивает в Mini App:
   - Source language: auto-detect
   - Target languages: EN, RU, DE (или "по языку пользователя")
   - Режим: reply-перевод (не спамит в чат) vs публичный (перевод ниже)

Тарификация группы:
- Счётчик символов общий на группу
- Оплачивает владелец группы
- Group quota = отдельный тариф

Edge-cases:
- Бот без прав → /permissions_help
- Сообщение на языке большинства → не переводить (экономия)
- Caption у медиа → только caption
```

## 4. Что НЕ делаем в v1

| ❌ | Причина отложили |
|---|---|
| STT для голосовых | Отдельный дорогой модуль |
| Перевод документов/файлов | Сложная обработка форматов |
| MTProto / Userbot | Риск бана, юридические вопросы |
| Собственный MT-движок | Используем внешние API |
| Мобильное приложение | Mini App достаточно |
| История переводов > 30 дней | Экономия на хранении |
